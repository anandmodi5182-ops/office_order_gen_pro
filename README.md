# ગુજરાતી કાર્યાલય આદેશ જનરેટર

આ GitHub Pages માટે તૈયાર કરેલી static HTML આવૃત્તિ છે. તેમાં મૂળ Office Order Generator ની સુવિધાઓ જાળવી રાખીને responsive layout, વધુ સ્પષ્ટ ફોર્મ controls, sticky preview toolbar, mobile-friendly spacing અને print styling ઉમેરવામાં આવ્યા છે.

## GitHub Pages પર પ્રકાશિત કરવું

1. GitHub માં નવું repository બનાવો, ઉદાહરણ તરીકે `gujarati-office-order`.
2. આ ફોલ્ડરની `index.html` ફાઇલ repository ના root માં upload કરો.
3. Repository માં **Settings → Pages** ખોલો.
4. **Deploy from a branch** પસંદ કરો, branch `main` અને folder `/ (root)` પસંદ કરીને Save કરો.
5. થોડા સમય પછી GitHub Pages આપેલી વેબસાઇટ લિંક ખોલો.

## અગત્યની નોંધ

- GitHub Pages static hosting છે. આ ફાઇલમાં રહેલું client-side login સુરક્ષિત authentication નથી. જાહેર repository માં HTML/JavaScript જોઈ શકાય છે અને અંદર લખેલા username/password પણ શોધી શકાય છે.
- સંવેદનશીલ સરકારી/શાળાકીય માહિતી અથવા વ્યક્તિગત દસ્તાવેજો માટે જાહેર hosting કરતાં મંજૂર ખાનગી hosting/સ્થાનિક ઉપયોગ પસંદ કરો.
- PDF વાંચવા, OCR, Word export અને Gujarati font માટે કેટલાક external CDN/Google Fonts internet connection માગી શકે છે.
- GitHub પર ફાઇલ તૈયાર કરી શકાય છે, પરંતુ તમારા GitHub ખાતામાં સીધું upload/publish કરવા માટે repository access અથવા તમે જાતે upload કરવાની જરૂર છે.
